# prompt Flow

This project defines a declarative CrewAI Flow in `src/prompt/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/prompt/flow.yaml` to change the flow. Add reusable crews under `src/prompt/crews/`, custom Python tools under `src/prompt/tools/`, and shared knowledge files under `src/prompt/knowledge/`.
